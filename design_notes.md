# Kata Catalogue: Design Notes

## Project Overview
A static site catalog of karate kata, with primary focus on the JKA (Japan Karate Association) canon, plus cross-reference support for other styles (starting with the five Pinan kata in Shito-ryu).

## Key Objectives
- Complete JKA syllabus: 25 official tournament kata, plus Ji'in as #26 (non-tournament, placed immediately below the 25).
- Clean data separation: normalized YAML databases for stances, techniques, individual kata, and cross-style equivalents.
- Cross-style comparison: Shito-ryu Pinan series mapped to Shotokan Heian equivalents.
- Full Japanese linguistic support: Kanji, Hiragana/Furigana (via HTML `<ruby>`), Romaji, and English translation.
- Interactive 3-way linguistic toggle: Japanese (Kanji + Furigana), Romaji, and English, with hover tooltips revealing other forms.
- Color-coded move categories: blocks, punches (`tsuki`), strikes (`uchi`), kicks, and other. Punches and strikes share a warm hue family.
- Global and kata-level analytics: stance frequency, move category ratios, kiai positions.
- Tagging system: categorizes kata by kyu grade (`9th_kyu` to `1st_kyu`, `kyu_grade`), `shitei` (Kihon, Heians, Tekki Shodan), `sentei` (Bassai Dai, Kanku Dai, Jion, Enpi), and `black_belt` (starting at Bassai Sho onward). Autogenerated tag listing pages cross-style, grouped by style.
- Provenance and review status tracking: starts at `early_draft`, promoted to `full_draft` when verified against canonical literature.
- Zero-dependency static output generated by a Python build script.

## Settled Architectural Decisions
- **JKA Canon Scope**: 25 main JKA kata + Ji'in listed as #26.
- **Pinan Comparator Style**: Shito-ryu. Preserves Anko Itosu's sequence (Pinan Shodan <-> Heian Nidan; Pinan Nidan <-> Heian Shodan) and contrasting stance mechanics.
- **Step Representation**:
  - `id`: e.g. "1", "25a", "25b"
  - `count`: integer base count (e.g. 25)
  - `subcount`: optional string ("a", "b", or null)
  - `stance`: key referencing `techniques/stances.yaml`
  - `lead`: `left` | `right` | `both` | `none`
  - `technique`: key referencing `techniques/techniques.yaml`
  - `secondary_technique`: optional secondary key
  - `target`: `jodan` | `chudan` | `gedan` | `null`
  - `turn`: discrete string (`left_90`, `right_180`, `0`, etc.)
  - `facing`: compass direction (`N`, `S`, `E`, `W`, `NW`, `NE`, `SW`, `SE`)
  - `kiai`: boolean
  - `notes`: brief description of movement and footwork
- **Orientation Validation**: Python build script consistency-checks `turn` against `facing`, issuing warnings on discrepancies.
- **Technique Categories**: 5 categories: `block`, `punch` (tsuki), `strike` (uchi), `kick`, and `other`.
- **Linguistic Switcher**: 3-way toggle (Japanese / Romaji / English). Single `name` field in kata header serves as English/Romaji name. Kanji and furigana stored separately.
- **Cross-Style Navigation**: Standalone static HTML pages per kata, visually unified with top tab bars that link between style equivalents.
- **Tag Taxonomy**:
  - `kyu_grade`: Heians and Tekki Shodan.
  - `shitei`: Kihon kata, Heian 1-5, Tekki Shodan.
  - `sentei`: Bassai Dai, Kanku Dai, Jion, Enpi.
  - `black_belt`: Bassai Sho onward.
- **Repository Structure**:
  - `kata/jka/`: 26 JKA kata YAML files.
  - `kata/shitoryu/`: 5 Shito-ryu Pinan YAML files.
  - `techniques/stances.yaml`: Master stance dictionary.
  - `techniques/techniques.yaml`: Master technique dictionary.
  - `equivalents.yaml`: Cross-style lineage map.
  - `build.py`: Site builder, validator, and analytics compiler.
  - `templates/`: Jinja2/HTML templates.
  - `dist/`: Generated static site (gitignored to prevent commit clutter).
